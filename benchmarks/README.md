# Snapdragon Benchmarks

This directory contains performance measurements collected from supported Snapdragon hardware.

## Metrics

Each benchmark should record:

- Device model
- Snapdragon platform
- Operating system
- Model name and version
- Runtime
- Execution provider
- Compute unit
- Input shape
- Number of runs
- Average latency
- Peak memory
- Power information when available

## Example

```text
Device: <Snapdragon PC>
Model: <local AI model>
Runtime: <runtime>
Execution Provider: <provider>
Compute Unit: <CPU/NPU/etc.>
Runs: 100
Average Latency: <measured value>
Peak Memory: <measured value>
