# LearnSphere Demo Script

## 1. Introduce the Problem

Traditional AI tutors answer questions, but they do not continuously understand what a student knows, what they are struggling with, and what they should learn next.

LearnSphere addresses this using an adaptive, privacy-first learning model.

## 2. Upload Study Material

Upload a course PDF.

LearnSphere processes the document locally.

## 3. Knowledge Map

The application extracts important concepts and creates an initial knowledge map.

## 4. Diagnostic Assessment

Generate a diagnostic assessment from the uploaded material.

Answer the questions.

## 5. Adaptive Mastery

LearnSphere updates the mastery level of individual concepts based on the student's answers.

## 6. Next-Best Learning Activity

The system identifies the concept that should receive attention next.

This recommendation considers the learner's current mastery and retention.

## 7. Private Tutor

Ask a question about the uploaded study material.

LearnSphere retrieves relevant passages locally and provides a source-grounded response.

## 8. Snapdragon Demonstration

On a supported Snapdragon PC, demonstrate the local AI workload and record actual:

- inference latency
- memory usage
- execution provider
- compute unit
- device information

Do not use estimated or fabricated benchmark numbers.

## Final Message

LearnSphere transforms AI from a generic question-answering tool into a personalized learning companion while keeping the learner's study data local-first.
